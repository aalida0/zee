### Precise source identification

The original SARAH wiki's older SPheno low-energy implementation calls `BR1LeptonTo3Leptons` in `LowEnergy_[Model].f90`. SARAH FlavorKit uses a different generated rate assembler, **`Calculate_Lto3Lp`**, in **`FlavorKit_Observables_[Model].f90`**. An inspectable public generated reference exists:

- [restrepo/Zee-Toolbox, SPHENO/Zee/FlavorKit_Observables_Zee.f90](https://github.com/restrepo/Zee-Toolbox/blob/master/SPHENO/Zee/FlavorKit_Observables_Zee.f90), generated by **SARAH 4.8.5 on 24 May 2016**, blob SHA `0ad7d169c92117d1253f274684f5bc9197c67bb4`.
- Its `Calculate_Lto3Lp` source appears roughly at characters 3683–6818. It explicitly accepts ordered complex `K1L,R`, `K2L,R`, `O4lSLL/SRR/SLR/SRL`, `O4lVLL/VRR/VLR/VRL`, `O4lTLL/TRR`. It adds e² K1 to both vector spectators, then includes dipole, S/V/T contact, dipole–scalar/vector, scalar–vector and scalar–tensor interference.
- The generic rate prefactor is `m_initial^5/(512*pi^3)` divided by parent width. The photon operator group uses e² and e⁴ factors, with `e²=4*pi*alpha(MZ)` in this generated example.
- This is **a source reference for a common observable convention**, NOT the same ZeeTypeII model implementation and NOT a validated physical rate. It is an older SARAH version, so any factor/phase transfer must be checked against the user's 4.15.4 source.

The original generated Fortran bundle from the user contains only `FlavorKit_LFV_ZeeTypeII.f90`, `Couplings_ZeeTypeII.f90`, `LoopFunctions.f90`. It does not contain a model-specific `FlavorKit_Observables_ZeeTypeII.f90` or `LowEnergy_ZeeTypeII.f90`. It is possible the entire observables stage was not generated in the archived source directory; that possibility is not proof without a recursive filesystem check.
